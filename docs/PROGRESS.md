## 内容量 vs 对标

| 维度 | 本站 | GameWith | DotGG |
|------|------|----------|-------|
| 角色深页 | **10** | ~70+ Legendary 全覆盖 | 大量 + 作者文 |
| 单页信息密度 | Quick Build 表 + 短文 | 技能表/星级/武器/塔罗/评分全 | 散文 build 意见 |
| 装备库 | 0 | 完整 | 多条 tier |
| 视觉 | 无立绘、无图标 | 角色图+UI 组件 | 中等 |
| 更新节奏 | 种子数据 | 版本日更新 | 作者不定期 |
| 筛选 | 几乎无 | Role/Faction/Tier 表 | 列表导航 |
| 信任 | 新站 | 品牌矩阵 | 作者 IP |

**简陋的本质不是 UI 主题色，而是：可索引实体太少 + 单页信息不够「查完就走/查完再点」的 wiki 密度。**

## 下一阶段建议（按杠杆排序）

### 阶段 A — 内容填肉（1–2 周，最高优先）

不先做花活 UI，先把「能搜能查」做厚：

1. **角色扩到 Top 40**（再冲全 Legendary）  
   - 每页：真实技能名、推荐装、星级优先级、2–4 段 how-to、同 Role 内链  
2. **Tier list 按 Role 分表** + 更新日志一行  
3. **装备最小库**（从角色推荐反推 30–50 件）  
   - `/weapons/{slug}` 有「Best on」回链  
4. **Guides 补到 6 篇**：party building、early teams、shard priority、reroll 长文  

目标：索引页 **80–120**，角色页不再像演示站。

### 阶段 B — 体验拉近对标（与 A 并行或紧接）

1. 角色卡片：角色色块/首字母 avatar → 有权限再换官方允许素材  
2. Characters 页：Role / Faction / Tier **筛选**  
3. 角色页：技能表、Build 多套（PvE / 通用）  
4. 首页：热更区块接真实 lastUpdated，去掉空分类的「骗点击」感（或标 Coming）  

### 阶段 C — 增长

1. GSC 验证 + sitemap  
2. Reddit r/SwordofConvallaria 价值贴（Builder / Tier）  
3. 新角色 24h 上线节奏  

### 明确先不做

- 剧情全文 walkthrough  
- 账号 / UGC 评论  
- 中文全站  
- 重金广告位（内容未厚时 AdSense 易低质）
